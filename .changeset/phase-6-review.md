Phase 6 review fixes (P6-13), in tools not yet released. `get_asset_history` now refuses a window older than `maxAsOfAgeDays`, does not follow `Scope`, ignores the order of multi-valued relations, and explains an over-long history instead of a generic size error. `get_attachment` no longer echoes the uploader's content type in an error message, no longer repeats the text in `structuredContent`, and audits the asset and attachment id of a refused or failed download. `release_readiness` can say `ready` for an epic with more than 100 backlog items, and a roll-up percentage is by estimate only when every item has one (`unestimatedItemCount` says how many do not). `defect_triage` reads the oldest change first (`search_work_items` gains `sort_by: oldest_changed`) and tokenises each name once; `work_item_quality` checks Given/When/Then in linear time. `get_sprint` classifies closed items without a status the same way at every burndown point and reports `partial` when rows outside the workspace were left out, as the composite reports now do. `resources/list` makes no Agility request, independent metadata loads go out together, prompt arguments refuse Unicode format characters, the stdio server serves the `history` group, and the redaction of large plain text is about 30 times faster.
