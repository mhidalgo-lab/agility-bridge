Consistency pass over the 26 tools (P6-12). Shared arguments (`asset`, `project`, `team`, `sprint`, `member`, `time_range`, `status`, `limit`, `cursor`, `format`, `include_closed`, `minimal_output`) now have one description each, from one schema, and every tool uses it; titles, the paging and cost sentences and descriptions open the same way everywhere ("Cold call: up to N Agility requests"). `list_members` now refuses a cursor that is not its own even when the workspace's projects list no members. `list_my_work` and `list_recent_changes` rows start with the identity columns like every other list (`number`, `assetType`, `oid`, `state`, `project`, then the tool's own columns). `get_sprint` (not yet released) names its counts `itemCount` instead of `items` (`totals`, `byStatusCategory[]`, `committed`, `planned`, `carryOver`, burndown points), and `sprint_health` reads them under the new name. `get_assets`, `list_asset_types`, `get_team`, `get_work_item` and `whoami` now declare the `partial` and `notes` keys they already returned in their output schemas. The advertised output schemas no longer repeat `additionalProperties: {}`: the default `tools/list` shrank from 39,179 to 35,892 bytes and the every-group one from 47,946 to 44,157 bytes, and the tool descriptions were reworded so the lexical router eval improved (65.8 % to 75 % top-1). No argument or released output field was renamed, so there is no deprecation alias.
