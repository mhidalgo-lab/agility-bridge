# P8-06 — Client integrations (Claude Code plugin, VS Code and Copilot snippets)

> Refined 2026-10-30 (Phase 8 batch).

## Goal
One-step installs in the clients that support packaged integrations, from one source of truth.

## Scope
- **Generator** (`apps/cli/src/client-snippets.ts`, command `agility-bridge client-config <client>`): the stdio entry for
  VS Code (with the `vscode:mcp/install` link and its web redirect), Claude Code (`claude mcp add`), Claude Desktop,
  Cursor (with its deep link), Copilot CLI and Windsurf. No snippet holds a token: a prompt or variable the client
  expands, a placeholder, or a `keychain:<name>` reference (P8-08). `--url` is validated; `--version` pins the package.
- **Claude Code plugin** in the repository (`plugins/agility-bridge`, marketplace file `.claude-plugin/marketplace.json`
  at the root): the MCP entry with `userConfig` prompts (instance address; a `sensitive` token), slash commands
  (my work, find an item, sprint status, standup) and two skills (workflows over the tools; untrusted-data and
  read-only conduct). Its `.mcp.json` is generated by the same module as the snippets.
- **MCP Registry**: `server.json` kept valid (checked offline here), with `docs/guide/registry-listing.md` describing
  the publish steps.
- **Version sync**: the plugin manifest and its pinned package version join `server.json` in `release.ts sync-version`
  and its `--check` (part of `pnpm lint`); a test compares every generated file with the committed one and checks the
  `server.json` environment variables against the known settings, the plugin against Claude Code's manifest rules, and
  every file for secrets.

## Acceptance criteria
- [x] One generator feeds the command, the plugin's `.mcp.json` and the docs; tests fail on drift.
- [x] Version sync covers plugin manifest and pin, and `--check` is in lint.
- [x] No snippet, link, plugin file or registry file holds a token (test with a token-shaped scan).
- [x] The plugin has the MCP entry, commands and skills, prompts for its settings with the token marked sensitive.
- [ ] Installs verified in each client with its version and date (owner step: needs the real clients; every snippet and
      link is *unverified* until then).
- [ ] Registry entry validated with `mcp-publisher validate` and published; plugin listed in a marketplace (owner steps:
      external registries; see `docs/guide/registry-listing.md`).
