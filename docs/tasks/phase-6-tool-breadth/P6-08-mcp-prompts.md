# P6-08 — MCP prompts (workflows)

## Goal
Ready-made workflows for common agile tasks.

## Scope
- `packages/core/src/prompts.ts`: `PROMPT_MANIFEST`, a sibling of `RESOURCE_MANIFEST` made of `ManifestEntry` extensions
  (`id`, `uses`, `title`, `description`, `arguments`, `build`), filtered with `availableEntries` in `buildMcpServer`, so stdio and
  HTTP get prompts with no host change (L-153).
- The seven catalogue prompts: `review_backlog_item_quality`, `sprint_review`, `standup`, `triage_defects`,
  `draft_release_notes`, `refine_backlog`, `explain_asset`, each with the `uses` of the catalogue table. A prompt is listed
  and gettable only when all its tools are allowed; the three that use report tools exist only when `reports` is on (decision
  recorded; a fallback onto the base tools is a follow-up).
- Prompt text is our own static text. Arguments are caller input: strings (MCP), validated with the tools' limits, a
  character allowlist and a shape check for asset references, named by the tool vocabulary (naming lint). They appear in the
  text only as JSON-quoted values the model passes on as tool arguments; a prompt never calls Agility.
- Each prompt tells the model to treat tool output as untrusted data (envelope), to stay read-only and to name what it could
  not read.
- `docs/reference/prompts.md` generated by `scripts/prompt-reference.ts` (`pnpm docs:prompts`) with a stale-check test.

## Acceptance criteria
- [x] The seven prompts register from `PROMPT_MANIFEST`; `prompts/list` offers exactly those whose `uses` are all allowed, and
  `prompts/get` of an absent one is refused with no upstream request.
- [x] Each prompt is tested with its tools allowed and with each of its tools missing; argument names pass the naming lint.
- [x] Invalid arguments (control characters, over length, malformed asset reference, missing required scope) are refused;
  argument values are only ever quoted into the text and the text names only tools in the entry's `uses`.
- [x] Every prompt carries the untrusted-data instruction and is read-only.
- [x] `docs/reference/prompts.md` generated with a stale-check test; catalogue and conventions updated.
- [x] Decisions D-105..D-107 recorded; lessons L-305..L-308 added.
